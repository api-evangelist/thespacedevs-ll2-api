TheSpaceDevs LL2 API is the Launch Library 2, a comprehensive space launch and events database delivering data on rocket launches, space events, astronauts, spacecraft, space stations, and crewed spaceflight missions worldwide. Provides real-time updates on launch schedules, mission timelines, and spacecraft operations.

**Areas:** Space · Satellite · Launches · Rockets · Astronauts

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for TheSpaceDevs LL2 API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
